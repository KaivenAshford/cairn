# pipeline

定时采集个人数据，产出 JSON 给 `web/` 构建时使用。

计划中的数据源，按独家性排序：

| 源 | 产出 | 独家性 |
|---|---|---|
| Claude Code transcripts（`~/.claude/projects`） | 与 AI 协作的真实统计 | 极少人公开真数据 |
| tsgo ArkTS 迁移进度（testdata + 诊断表） | 迁移看板 | 全球独一份 |
| git / gitcode 活动 | 时间花在哪些子系统 | 中 |
| 读书 / 听歌 / 运动 | 软数据 | 低，最后做 |

**铁律**：每个数据模块必须回答一个具体问题并配一句结论。
「今年 commit 1234 次」没人看第二眼；「今年 60% 的 commit 落在两个文件里」才有意思。
